Organizer headshots, referenced by `photo` in `src/content/dashboard.ts`.

Name each file after the person, lowercase and hyphenated — for example
`seth-lifland.jpg` — then set that person's `photo` to `/organizers/<file>`.
A person with no `photo` falls back to a gradient plate, so the grid stays
correct while photos are still coming in.

Portrait crops work best: the slot is 4:5 and the image is cropped to fill.
